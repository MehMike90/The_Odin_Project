Elements and Tags

Elements are like containers for HTML content. They tell the browser to produce say a paragraph or give a link to an image ect. An Element consists of an opening tag, content and a closing tag like below.


<p>This is a Paragraph Element</p>

The opening tag is the "<p>"
The content is the text "This is a Paragraph Element"
and the closing tag is the </p>

The browser can determine the end of an element because the closing tag has a forward slash "/"

There are elements called void elements which do not have closing tags like the "image" or "break" tags

<img> and <br>

These are void elements because they are void of any content. A break doesnt have content inside of it
to move the next load of text to a new line and an image doesnt have content because its an image.
