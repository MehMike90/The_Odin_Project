Lists

Unordered Lists

Unordered lists are used with the <ul> element. Nested inside of this element would be the actual list
enclosed in <li> tags. Each item in an unordered list begins with a bullet point.

Code:

<ul>
 <li>Item 1</li>
 <li>Item 2</li>
 <li>Item 3</li>
</ul>

Result:

  • Item 1
  • Item 2
  • Item 3

Ordered Lists

Ordered List are used with the <ol> element. The actual list is still nested inside of this element using
the <li> tags like the unordered list. Each item inside the ordered list starts with a chronological number.
This helps with things like a recipes step by step instruction or a top 10 favourites list ect.

Code:

<ol>
 <li>Item 1</li>
 <li>Item 2</li>
 <li>Item 3</li>
</ol>

Result

  1. Item 1
  2. Item 2
  3. Item 3

There is a small shortcut in a list if looking to add many items to a list. You can type in VSCode
'li' without the quotes followed by a '*' to multiple and a number. This number is how many items
you are wanting in your list. Example 'li*100' will give me 100 <li></li> typed out ready to go.
