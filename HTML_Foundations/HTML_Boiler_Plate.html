Boiler Plate

Every HTML document starts with a doctype declaration. This declaration is to tell the browser what
HTML version to use. The latest version currently is HTML5 and this uses...

<!DOCTYPE html>

After declaring the doctype we need to provide a <html> element. This is what is known as the "Root"
element of the document. Every other element of the document will be a decendent of this element.
This becomes important when manipulating the document using Javascript but for now we just need to
make sure its included in every HTML document.

The html element has an important "attribute" which needs to be included. This is the "Lang" attribute.
The "lang" attribute specifies the language of the text content in that element.
As its inside the HTML element with is the Root element, all decendent elements will inherit this
language unless specified in the future seperately.

Attributes will be mentioned in more detail in the future.

The next element in a boiler plate is the "<head>" element. The head element is were you put important
meta information. Its the element to use to put stuff which helps render web pages correctly
in the browser. We dont put anything in the head thats going to be displayed on the web page.

Inside the head element a "meta" element with charset encoding of the webpage needs to be in place.

meta charset="UTF-8

This helps the browser display special symbols and characters from other languages correctly.

The next element inside the head would be the "Title" element. This gives the user a human readable
title for the webpage as opposed to the HTML documents file path being shown in the working tab
of the browser. This helps navigate between multiple open tabs too is the user uses many at once.

There are more elements that go into the "Head" of a HTML document but for now these are the basics.

Moving on to the main compoment of the boiler plate... The 'Body' element!
This element is were all the content that is displayed by the user is going to be placed like,
The text of the document, images, links and so on... The body element is always placed after the head.

Example Boiler Plate

<!DOCTYPE html>
 <html lang="en">
  <head>
   <meta charset="UTF-8">
   <title>My First Webpage</title>
  </head>


  <body>
  </body>
 </html>
